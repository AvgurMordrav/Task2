# Запуск распределённой упаковки на одном компьютере

Все команды выполняются в терминале Linux. Нужны .NET 10 SDK, ASP.NET Core Runtime и ASP.NET Core Targeting Pack. В Arch Linux, если они ещё не установлены:

```bash
sudo pacman -Syu dotnet-sdk aspnet-runtime aspnet-targeting-pack
```

Для запуска нужны три отдельных окна или вкладки терминала; в каждом сначала перейдите в папку `Task2`.
## 1. Первый сервис

В первом терминале выполните:

```bash
cd Task2
dotnet run --project GeneticPacking.Service -- --urls http://127.0.0.1:5000
```

Дождитесь сообщения `Now listening on: http://127.0.0.1:5000`. Оставьте терминал открытым.

## 2. Второй сервис

Во втором терминале выполните:

```bash
cd Task2
dotnet run --project GeneticPacking.Service -- --urls http://127.0.0.1:5001
```

Дождитесь сообщения `Now listening on: http://127.0.0.1:5001`. Этот терминал тоже оставьте открытым.

## 3. Управляющее приложение

В третьем терминале выполните:

```bash
cd Task2
dotnet run --project GeneticPacking.App
```

В открывшемся окне выберите режим **«Распределённый»**. В поле **«Адреса сервисов»** укажите оба адреса, каждый с новой строки:

```text
http://127.0.0.1:5000
http://127.0.0.1:5001
```

Задайте параметры или выберите один из трёх готовых наборов и нажмите **«Запустить»**. Приложение отправит задачу обоим сервисам и покажет лучший полученный результат. Кадры отображаются с интервалом в одну секунду. Кнопка **«Остановить»** прерывает запросы; на экране остаётся последний показанный результат.


## 4. Сценарные тесты сервиса

Откройте ещё один терминал и выполните:

```bash
cd Task2
dotnet build GeneticPacking.Service
dotnet run --project GeneticPacking.ServiceTests
```

Тесты сами запускают отдельный экземпляр сервиса на `127.0.0.1:19587`, поэтому этот порт должен быть свободен. Уже работающие сервисы на портах 5000 и 5001 останавливать не нужно. Тесты проверяют доступность, получение поколений и корректность упаковки, отклонение неверных параметров и доступность сервиса после отмены запроса.

При успешном выполнении появится сообщение:

```text
Успешно: доступность, поток поколений и корректность упаковки, неверные параметры, разрыв соединения.
```
